# C++ Algorithms and Data Structures

> Four C++ problems: a numbers-game solver, a string optimiser, a linked list and a puzzle solver.

🔒 The code sits in a private repository because this was King's College London coursework. Ask me and I'll walk you through it.

## Parts
1. **Countdown numbers solver:** builds candidate sums in Reverse Polish Notation, evaluates them, and finds the one closest to the target
2. **String construction:** finds the cheapest way to build a target string from append and clone steps by spotting substrings it can reuse
3. **Linked list:** `LinkedList` and `Node` classes with iterators, insert and erase, front and back access, and in-place reverse, built with a Makefile
4. **Number-placement puzzle solver:** about 700 lines of constraint propagation. It tracks the possible values for each cell, splits rows and columns into compartments, strikes out impossible values and checks for clashes until it solves the board
