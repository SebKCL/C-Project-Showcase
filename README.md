# C++ Algorithms and Data Structures

> A four-part C++ project covering search, dynamic programming, data structures and a constraint-based puzzle solver.

🔒 **The source code is in a private repository** because this was university coursework at King's College London. I'm happy to walk through the code on request.

## Parts
1. **Countdown numbers solver:** generates candidate expressions in Reverse Polish Notation, evaluates them, and searches for the expression closest to the target number
2. **String construction optimiser:** finds the cheapest way to build a target string from append and clone operations, by detecting reusable substrings
3. **Linked list:** a `LinkedList` / `Node` implementation with iterators, insert/erase, front/back operations and in-place reverse, built with a Makefile
4. **Number-placement puzzle solver:** a constraint-propagation solver, around 700 lines long, that tracks each cell's possible values, splits rows and columns into compartments, removes impossible values and checks for conflicts until the board is solved

## Skills demonstrated
C++ · memory management · recursion and search · constraint propagation · unit test drivers
